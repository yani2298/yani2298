### 👨‍💻 About Me

Software Engineer passionate about crafting **high-performance client software, scalable cloud architectures, and production-ready AI solutions**. Focused on building reliable, clean, and intuitive digital experiences.

- 💻 **Ecosystems**: macOS native & cross-platform applications (Swift, Tauri, Electron) and modern Web platforms.
- ⚙️ **Architecture**: Event-driven services, microservices, REST & real-time APIs, robust data storage.
- 🤖 **Artificial Intelligence**: LLM orchestration, RAG pipelines, fine-tuning workflows, and on-device inference.
- 🔒 **Quality & Security**: OAuth/JWT authentication, API hardening, performance profiling, and CI/CD pipelines.
